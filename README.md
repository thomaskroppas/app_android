# Варианты почты через точку

Статическая страница (`index.html`) для GitHub Pages. Вводишь почту — страница выдаёт все варианты с точками:
сначала без точек, потом все с одной точкой (точка сдвигается на одну букву), потом с двумя
(первая стоит, вторая едет вправо; затем первая сдвигается) и так далее.

- «Следующая почта» — первый неиспользованный вариант: «Скопировать», «Отметить использованной».
- У отмеченного варианта ставится дата; сверху видно дату последней регистрации.
- В списке: ⧉ — скопировать, ✓ — отметить, ↺ — снять отметку.
- «Сбросить» — снять все отметки для текущей почты.
- «Поменять почту» — открыть другую почту.

## Где хранятся отметки

В Firebase Realtime Database проекта `mail-randomizer-github`, по ключу почты:
`emails/<почта>/used/<номер варианта> = время отметки`. Входа нет: любой, кто введёт ту же почту,
видит и меняет те же отметки. Какая почта открыта — помнит сам браузер.

Правила базы (Firebase → Realtime Database → Rules):

```json
{ "rules": { "emails": { ".read": true, ".write": true } } }
```
