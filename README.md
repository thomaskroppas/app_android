# Варианты почты через точку

Статическая страница (`index.html`, без зависимостей). Вводишь почту один раз — страница выдаёт все варианты с точками:
сначала без точек, потом все с одной точкой (точка сдвигается на одну букву), потом с двумя
(первая стоит, вторая едет вправо; затем первая сдвигается) и так далее.

- «Следующая почта» — первый неиспользованный вариант, кнопки «Скопировать» и «Отметить использованной».
- В списке у каждого варианта: ⧉ — скопировать, ✓ — отметить, ↺ — снять отметку.
- «Поменять почту» — ввести другую; отметки хранятся отдельно для каждой почты.
- Всё хранится в `localStorage` этого браузера.

Открыть: просто файл в браузере или включить GitHub Pages (Settings → Pages → branch).
